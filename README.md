# ScreenScan RPA 智能工作台

基于图像特征匹配、Windows 原生 WinOCR 文字识别与状态机流转的工业级自动化 RPA 桌面工具。

---

## 🌟 核心特性与架构升级

1. **五元组统一规范与安全流转**:
   - 规则探测统一返回 `(matched, info, coord, score, candidate)` 5 元组规范，杜绝未捕获异常；
   - 动作后执行多重验证（支持局部快速区域 OCR 验证与全图下一步探测），验证未通过自动阻断流转跳转，防止雪崩式误点。

2. **多变体智能 OCR 与精确定位**:
   - 采用 Windows 原生 WinOCR 引擎，支持 `[原图, CLAHE增强, Otsu二值化, 反色二值化]` 四重预处理变体；
   - 支持多语言切换：`zh-Hans-CN (简体中文)`、`en-US (English)`、`zh-Hant-TW (繁体中文)`、`ja-JP (日本語)`；
   - **数值条件运算**: 支持 `>、<、>=、<=、==、!=` 及 `[min, max]` 区间匹配，支持前缀业务标签（如 `库存 < 5`、`价格 <= 99.9`、`血量 < 30%`）；
   - **跨行相邻合并检测**: 即使 OCR 将“库存”与“5”识别为上下两行，也会智能合并判定并精准把点击坐标定位到数字所在区域；
   - 当 OCR 识别到文字但无法提取有效字词边框时，自动置 `coord=None`，复合动作整链拦截以杜绝向焦点窗口误输。

3. **复合动作序列引擎**:
   - 单步骤内支持配置动作序列（例如 `点击 -> 等待 0.3s -> 粘贴 -> 回车`）；
   - **分号与分隔符说明**: 强烈推荐使用 `->` 或 `→` 作为动作连接符，此时粘贴/输入内容中可安全包含分号（例如 `点击 -> 粘贴: user;pwd -> 回车`）；
   - **可中断安全等待**: 序列中的“等待 N 秒”内置 60 秒安全硬上限，并支持分片检测（每 0.15s 响应 F7 暂停 / F9 停止），随时立停。

4. **安全自卫与物理护栏**:
   - **窗口白名单校验**: 点击前通过 Win32 `WindowFromPoint` 校验目标窗口标题与进程名，不在白名单则安全跳过；
   - **单实例运行互斥锁**: 基于 Win32 原生 `CreateMutexW`，多开自动弹出原生提示并退出，避免抢鼠标和覆盖配置；
   - **全黑截屏检测**: 自动检测截图画面平均亮度，当画面纯黑时（如 DirectX/OpenGL 独占全屏或 DRM 保护）主动提示切换为窗口化；
   - **证据截图自动轮转**: 自动维护最新 50 张 `evidence_*.png` 留证截图，防止长期挂机撑满磁盘空间；
   - **Dry-Run 仿真演练**: 勾选后仅执行检测与流程跳转，绝不发出任何物理点击与按键。

5. **多显示器全屏与阈值调参助手**:
   - 支持多显示器跨屏框选与全虚拟桌面截图；
   - **阈值调参助手 (`ThresholdTuningDialog`)**: 采样 N 帧输出分数分布（最高/最低/均值/标准差）与推荐阈值，带实时命中框预览与准备就绪提示；
   - **模板命中唯一性判断**: 默认严格唯一（同屏多个目标时告警拒绝点击），并支持在步骤中显式配置 `取第 1 个`、`取第 2 个` 等。

## 🚀 快速上手

### 1. 环境准备
推荐使用 Python 3.9 ~ 3.11 (Windows 64位):
```bash
pip install -r requirements.txt
```

### 2. 一键启动
进入 `ceshi1` 目录，双击运行：
```bash
一键启动.bat
```
或在终端执行：
```bash
python ceshi1/app.py
```

### 3. 全局热键
- **`[F7]`**: 即时暂停 / 恢复工作流（内置 400ms 防抖）
- **`[F8]`**: 启动工作流
- **`[F9]`**: 停止并安全释放鼠标键盘

> ⚠️ **运行提示**: 状态机运行期间将自动接管鼠标指针进行穿透点击，运行中请勿人工移动鼠标，如需操作电脑请先按 `[F7]` 暂停。

## 📋 日志与配置文件说明
- `rpa_rules.json`: 工作流步骤与规则配置列表。
- `rpa_settings.json`: ROI 区域持久化配置文件。
- `screenscan_rpa.log`: 软件运行时业务与状态机日志文件（单个上限 5MB，自动轮转）。
- `crash.log`: 一键启动脚本捕获的 Python 进程级崩溃与未捕获异常日志。
