# ScreenScan RPA 智能工作台

基于图像特征匹配、Windows 原生 WinOCR 文字识别与状态机流转的工业级自动化 RPA 桌面工具。

---

## 🌟 核心特性与架构升级

1. **五元组统一返回值与异常保护**:
   - 规则探测统一返回 `(matched, info, coord, score, candidate)` 5 元组规范，支持安全解包并消除所有未捕获异常。
2. **多变体智能 OCR 与精确定位**:
   - 采用 Windows 原生 WinOCR 引擎，支持 `[原图, CLAHE增强, Otsu二值化, 反色二值化]` 四重预处理变体；
   - 坐标根据预处理缩放比例自动反算（原图 1.0x，变体 2.0x），保证点击精度；
   - 当 OCR 识别到文字但无法提取有效字词边框时，自动置 `coord=None`，杜绝误点屏幕左上角 `(0, 0)`。
3. **安全自卫与物理护栏**:
   - **Dry-Run 仿真演练**: 勾选后仅执行检测与流程跳转，绝不发出任何物理点击与按键；
   - **窗口自卫规避**: 自动检测点击目标是否位于本工具自身窗口内，主动拦截自指误点；
   - **单步真实点击测试**: 自动提取当前 ROI，2 秒倒计时平滑切换目标窗口，支持自卫拦截；
   - **运行上限熔断**: 可设定最大执行动作次数（如 50 次）与最大运行时长（如 1800 秒），防止死循环跑飞。
4. **ROI 局部监控与坐标对齐**:
   - 支持全屏监控与局部框选 ROI 监控；
   - 颜色取样规则在 ROI 模式下自动计算相对坐标，修正双重叠加偏差；
   - ROI 区域配置持久化保存至 `rpa_settings.json`，重启软件自动恢复。
5. **多候选图分支与专属终止**:
   - 单步骤支持多张候选图片，支持候选级独立流转与专属 `stop` 终止指令；
   - 候选图命中后支持 P1~P99 权重优先级并发冲突仲裁。
6. **看门狗心跳与线程安全**:
   - 状态机工作循环独立于 UI 主线程，每轮更新心跳时间戳；看门狗只监控心跳超时，不再误按 ESC；
   - 吸管取色与日志刷新全部通过 Tkinter 线程安全调度（`self.root.after`），杜绝界面卡死。

## 🚀 快速上手

### 1. 环境准备
推荐使用 Python 3.9 ~ 3.11 (Windows 64位):
```bash
pip install -r requirements.txt
```

### 2. 一键启动
进入 `ceshi1` 目录，双击运行：
```bash
一键启动.bat
```
或在终端执行：
```bash
python ceshi1/app.py
```

### 3. 全局热键
- **`[F7]`**: 即时暂停 / 恢复工作流（内置 400ms 防抖）
- **`[F8]`**: 启动工作流
- **`[F9]`**: 停止并安全释放鼠标键盘

---

## 📋 配置文件说明
- `rpa_rules.json`: 工作流步骤与规则配置列表。
- `rpa_settings.json`: ROI 区域持久化配置文件。
- `screenscan_rpa.log`: 软件运行时业务与状态机日志文件（单个上限 5MB，自动轮转）。
- `crash.log`: 启动器捕获的 Python 崩溃与未捕获异常日志。

### 💡 关键使用须知
1. **模板命中不唯一保护**:
   - 若画面中出现多个相同的图标（如两个同款按钮），默认会拒绝误点并告警“命中不唯一”；
   - 若需指定点击第几个，可在规则或候选图里将【命中唯一性】配置为 `取第 1 个`、`取第 2 个` 等。
2. **OCR 数值条件（支持跨行识别）**:
   - 支持 `>、<、>=、<=、==、!=` 及 `[min, max]` 区间匹配；
   - 支持前缀标签（如 `库存 < 5`、`价格 <= 99.9`、`血量 < 30%`）；
   - 内置相邻行自动合并判定机制，即使 OCR 将“库存”与“5”识别为两行也能智能命中并准确定位。
